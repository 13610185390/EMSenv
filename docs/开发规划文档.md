## 1. 开发概述

### 1.1 项目信息
- **项目名称**：储能EMS教学仿真平台
- **技术栈**：Python 3.10+ / Gradio 4.x / Matplotlib / Plotly / Pandas
- **目标用户**：EMS售后工程师、开发人员
- **开发模式**：模块化开发、测试驱动

### 1.2 开发原则
1. **模块独立**：每个模块可独立运行和测试
2. **接口先行**：先定义接口，再实现逻辑
3. **测试覆盖**：核心逻辑必须有单元测试
4. **文档同步**：代码注释与技术设计文档保持一致
5. **渐进集成**：完成一个模块后立即集成测试

### 1.3 质量标准
- 代码通过 pylint 检查（评分 ≥ 8.0）
- 核心模块单元测试覆盖率 ≥ 80%
- 所有公开接口有完整的 docstring
- 无硬编码的魔法数字，使用配置常量

#### 1.4.2 Git 工作流程

1. **分支策略**
   - `main`: 主分支，稳定版本
   - `dev`: 开发分支，日常开发
   - `feature/xxx`: 功能分支，按模块创建

2. **提交规范**
   ```
   <type>(<scope>): <subject>

   类型(type):
   - feat: 新功能
   - fix: 修复bug
   - docs: 文档更新
   - refactor: 重构
   - test: 测试相关
   - chore: 构建/工具

   范围(scope): 模块名称，如 basic_params, simulation 等

   示例:
   feat(models): 添加BESSParams数据类
   feat(simulation): 实现仿真主循环
   fix(control): 修复SOC保护逻辑
   docs: 更新开发规划文档
   ```

3. **提交频率**
   - 每完成一个任务清单项提交一次
   - 每个阶段完成后打 Tag

4. **Tag 命名**
   ```
   v0.1.0 - 阶段0完成（项目初始化）
   v0.2.0 - 阶段1完成（基础架构层）
   v0.3.0 - 阶段2完成（核心功能层）
   v0.4.0 - 阶段3完成（展示层）
   v0.5.0 - 阶段4完成（教学增强层）
   v1.0.0 - 阶段5完成（正式版本）
   ```
